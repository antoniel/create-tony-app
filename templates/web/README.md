## Design Studio · Vite

Open `/studio` to browse the component hierarchy, pan and zoom, isolate components, and edit brand, accent and font tokens or component appearance. Changes save in your browser. Undo and Redo also cover moved and hidden nodes.

Export downloads a JSON backup, `design-tokens.ts` for `apps/web/src/theme/design-tokens.ts`, and `component-overrides.css` for `apps/web/src/studio/component-overrides.css`. Commit the exported source files to use the design as the default. Reset design returns a local draft to the shipped defaults.
